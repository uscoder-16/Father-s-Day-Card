# Father-s-Day-Card
Scratch fathers day Card
My Father's Day app in Scratch is a fun and creative project made to celebrate fathers. When the green flag is clicked, a Father's Day message appears on the screen, such as "Happy Father's Day, Dad!" The app includes colorful backgrounds, pictures, and animations to make it special. Users can click buttons to see kind messages, fun facts about fathers, or play a small game. This app is a great way to show love and appreciation for dads while learning how to code in Scratch.
